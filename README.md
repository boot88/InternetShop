# TechZone — каталог электроники и корзина

Веб-приложение на Laravel: каталог товаров с поиском и фильтрами, карточками товаров, регистрацией и корзиной.

**Статус:** развиваемый проект интернет-магазина. Каталог и корзина реализованы; страницы личного кабинета и заказов пока перенаправляют на главную с сообщением о разработке. Подключённую оплату и завершённый checkout эта версия не демонстрирует.

## Возможности

- Каталог с пагинацией и поиском по названию, описанию и артикулу.
- Фильтры по категории, бренду и диапазону цены; сортировка.
- Вложенные категории и связи товаров с категориями.
- Карточка товара с изображениями, вариантами, отзывами и похожими товарами.
- Регистрация, вход и выход.
- Корзина для гостевой сессии и авторизованного пользователя.
- Изменение количества, удаление позиций и очистка корзины.
- Миграции и сидеры для товарных и связанных данных.

## Технологии

PHP 8.2+, Laravel 12, Eloquent ORM, Blade, JavaScript, Alpine.js, Tailwind CSS и Vite. Подключение базы данных задаётся через Laravel-конфигурацию; пример окружения по умолчанию использует SQLite.

## Локальный запуск

Требуются PHP с расширениями Laravel, Composer, Node.js подходящей для Vite версии и выбранная СУБД.

```bash
git clone https://github.com/boot88/InternetShop.git
cd InternetShop
composer install
cp .env.example .env
php artisan key:generate
npm ci
npm run build
```

Настройте в `.env` отдельную локальную базу. Для SQLite создайте файл `database/database.sqlite`; для MySQL задайте `DB_CONNECTION`, `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME` и `DB_PASSWORD`.

```bash
php artisan migrate
php artisan storage:link
php artisan serve
```

Откройте `http://127.0.0.1:8000/products`.

Для наполнения **локальной демонстрационной базы** можно изучить и запустить `php artisan db:seed`. Не используйте сидеры с рабочими данными.
